# GM Table

Веб-приложение для проведения ролевых партий (D&D, Project Moon и другие системы) в реальном времени.

**GM Table** — это VTT (Virtual Tabletop), который объединяет классическую механику D&D с визуализацией сцен, токенов и инструментов мастера.

## 🎯 Что умеет

- **Комнаты:** создание, присоединение по короткому ID.
- **Сцены:** загрузка фонов, переключение, редактирование.
- **Токены:** персонажи игроков, NPC, объекты. Drag-n-drop, HP/SP, уровни, опыт.
- **Ассеты (Панель мастера):** заготовки токенов с папками и drag-n-drop на сцену.
- **Инструменты рисования:** карандаш, линии, стрелки, фигуры, текст. Метки и пинги.
- **Профили:** смена ника, сохранение сессии.
- **Real-time:** синхронизация всего через WebSocket.

## 🚀 Быстрый старт

### Требования

- **Node.js** 20+ (рекомендую 22+)
- **pnpm** 9+ (`npm i -g pnpm` или `corepack enable`)
- **Docker** + **Docker Compose**
- **PostgreSQL** (поднимается через Docker)

### 1. Клонирование

```bash
git clone <repo-url> gm-table
cd gm-table
```

### 2. Установка зависимостей

```bash
pnpm install
```

### 3. Настройка окружения

Скопируй `.env.example` в `.env`:

```bash
cp .env.example .env
```

Отредактируй `.env`:

- **`DATABASE_URL`** — строка подключения к Postgres.
- **`JWT_SECRET`** — длинный случайный секрет (64+ символов).
- **`POSTGRES_*`** — данные для Docker Postgres.

**Сгенерировать `JWT_SECRET`:**

```bash
openssl rand -base64 64
```

### 4. Запуск Postgres

```bash
docker compose up -d postgres
```

**Проверь:**

```bash
docker ps
```

Должен быть контейнер `gm-table-postgres` со статусом `healthy`.

### 5. Миграции БД

```bash
pnpm db:migrate
```

**Создать пустую БД, если её нет:**

```bash
docker exec -it gm-table-postgres createdb -U gm_table gm_table
```

### 6. Сборка shared

```bash
pnpm --filter @gm-table/shared build
```

### 7. Запуск

**В двух терминалах:**

**Терминал 1 (сервер):**
```bash
pnpm dev:server
```

**Терминал 2 (клиент):**
```bash
pnpm dev:client
```

**Открой:** `http://localhost:5173` (или порт из `.env`).

## 🎮 Первый запуск

1. **Введи email** на странице входа — аккаунт создастся автоматически.
2. **Создай комнату** в лобби через кнопку «+».
3. **Пригласи друзей** — поделись `shortId` комнаты.
4. **Создай сцену** (нужен фон).
5. **Создай персонажа** — модалка появится автоматически при входе в комнату.
6. **Играйте!**

## 🔐 Аутентификация

**Без паролей.** Email — единственный идентификатор.

- **Вход:** вводишь email → если аккаунта нет, создаётся.
- **Токен:** JWT, хранится в `localStorage`, живёт 30 дней.
- **Ник:** генерируется из email, можно менять в профиле.

## 📡 Real-time

Всё синхронизируется через **Socket.IO**:

- **Подключение:** с JWT из `localStorage`.
- **События:** создания, обновления, удаления.
- **Broadcast:** все участники комнаты получают изменения.

## 🗄 Что где хранится

**PostgreSQL (персистентно):**
- Пользователи.
- Комнаты, участники.
- Сцены.
- Токены.
- Ассеты, папки ассетов.
- Статусы (библиотека).
- Состояние комнаты (активная сцена, фаза хода).
- Заявки.
- Сообщения чата.

**In-memory (эфемерно):**
- Рисунки (карандаш, линии, фигуры, текст).
- Метки и пинги.

**localStorage:**
- JWT.
- `userId`.
- Настройки UI (цвет, толщина инструментов).


## 🐛 Известные ограничения

- **Нет чата** (будет позже).
- **Нет логики хода** (подтверждения, заявки).
- **Нет статусов на токенах** (библиотека есть, применение — позже).
- **Нет камеры** (zoom/pan) — сцена фиксирована 1920×1080.
- **Нет мобильной версии** (десктоп only).
- **Нет голосового чата** (используйте Discord).
