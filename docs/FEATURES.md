## 🐛 Известные баги / шероховатости

| Баг | Приоритет | Примечание |
|---|---|---|
| Реконнект после падения сервера требует перезагрузки | Средний | WebSocket reconnect не всегда восстанавливает состояние |
| «Вернуть всех в центр» — диагональная лесенка | Низкий | Красивое расположение (круг/спираль) — позже |
| «Вернуть мой токен» не учитывает занятость центра | Низкий | Добавить смещение, если центр занят |
| При перезагрузке страницы UI-настройки сбрасываются | Низкий | `activeTool` не сохраняется (только цвета/толщина) |
