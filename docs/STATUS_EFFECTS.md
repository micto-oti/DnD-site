# Статус-эффекты: согласованное поведение

- ГМ управляет библиотекой комнаты; игрокам доступны все эффекты для своих токенов.
- Первое наложение: сила 1, счётчик 1 (если предусмотрен).
- Повторное наложение открывает редактор существующего эффекта, без сложения значений.
- Нулевые значения не снимают эффект автоматически. Снятие ручное.
- Автоматического урона и изменения счётчика по ходам пока нет.

## Этап 1

Переключатель «Токены / Статусы» слева в панели ГМа. Библиотека содержит
поиск, создание и редактирование. Название, эмодзи и цвет редактируются;
наличие счётчика задаётся при создании. Изменения видны участникам через
Socket.IO и сохраняются в существующей statuses_library. Миграций нет.
Создание и изменение проверяют роль ГМа на сервере и идентификатор комнаты.
Удаление эффектов пока не реализовано.

## Этап 2: эффекты на токенах

- ГМ перетаскивает карточку эффекта из библиотеки на токен сцены. Цель подсвечивается.
  Бросок на пустое место не создаёт эффект.
- Под токеном отображаются иконки, сила и счётчик. Клик открывает редактор;
  чужой токен доступен игроку только для просмотра.
- В боковой панели «Объекты» выбери свой токен и нажми «+ Статус».
  Можно выбрать любой эффект комнаты. ГМ использует ту же кнопку для любого токена.
- Первое наложение даёт силу 1 и счётчик 1; у эффекта без счётчика — null.
- Повторное наложение открывает существующий эффект, не сбрасывая и не складывая значения.
- Нули сохраняются. Для удаления есть отдельная кнопка «Снять эффект».
- Изменения сохраняются в существующем JSON-поле токена и передаются участникам
  через `token:updated`; при повторном входе возвращаются в состоянии комнаты.

API: POST/PATCH/DELETE `/api/tokens/:tokenId/statuses/:statusId`.
Проверяются членство в комнате, роль ГМа или владение токеном, наличие определения
эффекта в этой комнате, целые значения и ограничения библиотеки.
Одновременные изменения защищены сравнением прежнего JSON при записи и повтором
при конфликте. Прямая передача массива statuses через общий token:update запрещена.
Миграций и автоматической обработки урона/ходов нет.
